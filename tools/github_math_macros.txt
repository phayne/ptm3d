# TeX macros in GitHub's math renderer (Markdown file view), measured.
#
# Derived from a saved, signed-in GitHub file view of docs/thermal-model.md. GitHub sends
# math as MathML: every node carries a data-latex attribute, and a macro the renderer does
# not define comes back as <mtext mathcolor="red"> holding the macro name (not <merror>:
# a check for errors alone misses it). \tag comes back as an <mlabeledtr> row, which the
# browser's own MathML layout does not support. MathJax 3.2.2 with MathML output (tex2mml,
# base + ams) shows the same two failures on the same page, so it is a useful local check,
# but only the GitHub page itself decides.
#
#   allow  <macro>            rendered as math (a non-red node, in an expression without errors)
#   block  <macro>  <reason>  fails on GitHub; the checkers report it as an error
#
# Anything else is "unverified": the checkers warn. To extend the list, save the GitHub
# file view of a page that uses the macro (browser "Save Page As", complete) and run
#   python3 tools/github_math_macros.py --derive SAVED.html

block \thickspace  undefined on GitHub: the macro name is printed in red. Around = + - < write the operator alone; between a number and a unit use \thinspace
block \tag  GitHub emits an mlabeledtr row that browsers do not lay out: the equation collapses into a column of symbols. Write \qquad \text{(B1)} at the end of the line
